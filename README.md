# 🏥 Doctor Appointment System

A specialized web application for managing healthcare appointments. This system bridges the gap between patients and doctors with an easy-to-use booking interface.

## 🌟 Features
* **Appointment Booking:** Simple form to schedule visits.
* **Database Integration:** Uses **MySQL** to store and manage patient data and schedules.
* **Backend Logic:** Powered by **JSP** (JavaServer Pages) for dynamic server-side processing.

## 🛠️ Tech Stack
* **Web:** HTML5, CSS3, JSP
* **Database:** MySQL
* **Configuration:** XML (`web.xml`)
